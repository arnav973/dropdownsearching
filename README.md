# AIAGENT

# Advanced AI Planning Widget for SAP Analytics Cloud

## Files
- widget.json
- webcomponent.js
- styling.js

## Host on GitHub Pages
1. Create a GitHub repository
2. Upload all files to the repository root
3. Enable GitHub Pages
4. Copy the hosted URL

Example:
https://yourusername.github.io/advanced-ai-planning-widget/widget.json

## Import into SAC
1. Go to SAC
2. Custom Widgets
3. Register widget
4. Paste the URL to widget.json
5. Add widget to your analytic application or story if supported

## Notes
- Configure `apiBaseUrl` and `apiPath`
- Best practice is to connect this widget to your own backend middleware
- Do not expose sensitive API keys in widget properties
